# NAMING STANDARD v1.0

Status: ACTIVE
Date: 2026-09-04

## Purpose

Define stable internal names and IDs while allowing consumer-facing names to evolve.

## Internal Names

Use stable machine-readable IDs from `docs/operations/ID_STANDARD.md`.

Examples:

- `CAPI-S01-001`
- `CAPI-S01-001-M001`
- `PT-CAPI-S01-001-0001`

## Public Names

Public names may be warmer and more marketable, but they must map to stable IDs in metadata.

## Folder Names

Drive folders may use readable labels like `CAPI_001`, but metadata must store the stable ID.
