# VISUAL DIRECTION EXPLORATION v1.0

Status: DRAFT - PHASE 1A
Date: 2026-09-04
Truth level: PROVISIONAL

## Purpose

Phase 1A explores three materially different candidate art directions for the CAPICAPI base character before any 3D master is modeled.

The goal is not to choose the cutest capybara. The goal is to identify a proprietary visual DNA that survives role, costume, material, and series changes.

## Phase 1A Boundary

Do not:

- model Capi v0
- freeze a consumer character
- select filament colors
- create Series 01
- approve a permanent production master

Do:

- define candidate visual directions
- generate/evaluate reference images later
- compare directions using identical views
- test whether visual DNA survives quick costume variants
- require human approval before Phase 1B

## Three Candidate Directions

These are exploration lanes, not final choices.

### Direction A - Grounded Loaf Collectible

Premise: a calm, rounded, grounded Capi with a low, compact body and strong capybara muzzle identity.

Distinctive questions:

- Can a simple loaf-like form remain proprietary?
- Does the muzzle/ear/eye language carry enough identity?
- Can costumes work without turning the figure into a generic bean mascot?

Risks:

- may become too generic if silhouette is not specific
- low body may limit costume readability
- side view must avoid becoming an anonymous oval

### Direction B - Designer Toy Mascot

Premise: a more upright, iconic collectible figure with stronger head/body separation while retaining capybara signals.

Distinctive questions:

- Can CAPICAPI become more character-forward without losing capybara anatomy?
- Are expressions and costumes more readable?
- Does the body become too human or too bear-like?

Risks:

- may drift into teddy bear/chibi mascot territory
- may invite fragile arms/accessories
- may need careful DFM adaptation later

### Direction C - Sculptural Totem Capi

Premise: a compact, stylized art-toy figure with simplified planes, stronger silhouette discipline, and bolder geometry.

Distinctive questions:

- Can a more sculptural form feel premium and proprietary?
- Does the simplified plane language improve FDM readability?
- Can role variants be communicated through relief and zones rather than many colors?

Risks:

- may feel less cute or less emotionally accessible
- expression range may be limited
- must avoid becoming abstract enough to lose capybara identity

## Required Evaluation Views

Each direction must eventually be evaluated with identical assets:

- front
- front 3/4
- side
- back
- silhouette
- neutral expression
- several expression examples
- quick costume tests

Quick costume tests:

- Biker
- Astronaut
- Doctor

Equivalent role tests are acceptable only if they cover hard accessory/costume cases.

## Evaluation Criteria

Score each direction against:

- recognition with costume removed
- distinction from generic cute animals
- capybara specificity
- expression range
- costume survivability
- silhouette clarity
- likely FDM friendliness
- color economy
- accessory-zone clarity
- collectibility
- ability to scale into series

Scores are advisory. Human approval is required.

## Decision Workflow

1. Generate candidate reference package for Direction A.
2. Generate candidate reference package for Direction B.
3. Generate candidate reference package for Direction C.
4. Normalize views and role tests across all directions.
5. Evaluate with the same scorecard.
6. Record gaps, risks, and rejected drift.
7. Human chooses: approve one, revise, combine specific traits, or reject all.
8. Only after approval, enter Phase 1B provisional visual master/reference pack.

## Output Package Per Direction

Each direction should produce:

- direction ID
- written premise
- visual references
- view sheet
- expression examples
- quick costume tests
- silhouette sheet
- risk notes
- DFM concern notes
- recommendation, if any

## Human Decision Required

The project owner must decide which visual direction enters Phase 1B. The agent may recommend, but must not autonomously select the final direction.
