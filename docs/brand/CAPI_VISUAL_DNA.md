# CAPI VISUAL DNA v1.0

Status: DRAFT - PHASE 1A
Date: 2026-09-04
Truth level: PROVISIONAL unless explicitly marked otherwise.

## Purpose

This document defines what makes a CAPICAPI character recognizable before any final 3D master is modeled. It is the visual identity contract that future Design and 3D Modeling Agents must use to evaluate whether a candidate remains a Capi across roles, costumes, materials, and series.

No final numeric proportions are approved in Phase 1A. Ratios, dimensions, spacing, and geometry values remain `TBD — REQUIRES APPROVED VISUAL MASTER` and may later remain `TBD — REQUIRES PHYSICAL TEST` until validated on the Bambu Lab A1.

## Recognition Test

A Capi must remain recognizable when costume and role-specific accessories are removed or ignored.

Recognition signals:

- capybara-derived head and muzzle language
- calm, collectible stance
- coherent head/body mass relationship
- simple readable eye family
- small integrated ears
- sturdy low leg/paw language
- rounded, manufactured-for-FDM form language
- accessory zones that support the base character rather than hiding it

If a candidate only reads as a Capi because of clothing, props, captioning, or context, it fails visual DNA.

## Head Silhouette

The head silhouette must be capybara-derived but stylized enough to be proprietary.

Must define later:

- front silhouette
- 3/4 silhouette
- side silhouette
- ear integration
- muzzle protrusion profile
- top-plane/forehead language

Forbidden drift:

- generic round bear head
- dog/cat/hamster silhouette
- realistic rodent skull
- anime mascot head unrelated to capybara anatomy
- helmet/accessory silhouette replacing the head identity

## Body Silhouette

The body should read as sturdy, calm, and collectible.

Must define later:

- standing/seated default mass
- shoulder/back curve
- belly plane
- rump/back-end language
- leg visibility
- stable base footprint

Forbidden drift:

- thin action-figure body
- realistic quadruped animal sculpture
- bean shape without capybara specificity
- costume volume replacing body identity
- fragile perimeter appendages

## Muzzle Proportions

Status: TBD — REQUIRES APPROVED VISUAL MASTER.

The muzzle is a primary Capi identity signal. It must be broad, simple, and readable without paint.

Must define later:

- muzzle width relative to head
- muzzle height
- muzzle projection in side view
- nose location
- mouth language
- relation to eye placement

Forbidden drift:

- tiny dot nose with no capybara snout
- long dog-like snout
- realistic whisker detail
- paint-only muzzle separation
- mouth shapes that require micro-detail

## Eye Family

The eye family must be simple enough for FDM and distinct enough to support expression.

Candidate eye families may include:

- calm capsule eyes
- dot/oval eyes with mild eyelid geometry
- inset bead-like eyes formed by geometry/color region
- low-relief eyes with brow/eyelid variants

Must define later:

- eye shape family
- eye scale
- eye depth/relief
- eye color/material role
- expression range

Forbidden drift:

- hyper-detailed eyes
- eyelashes
- glossy realistic eyes
- anime sparkle detail
- expression dependent on paint or sub-nozzle detail

## Eye Spacing And Placement

Status: TBD — REQUIRES APPROVED VISUAL MASTER.

Must define later:

- eye centerline height
- spacing relative to muzzle width
- distance from muzzle top
- front/side wrap behavior
- allowed asymmetry, if any

Rule: eye placement must be evaluated in front, 3/4, and side views. A face that works only from one view is not approved.

## Ear Family And Placement

Ears should be small, rounded, integrated into the head mass, and robust.

Must define later:

- ear shape family
- ear size
- ear root thickness
- top/side placement
- whether inner-ear relief is allowed

Forbidden drift:

- large bear ears
- rabbit/hamster ears
- thin tabs
- separate accessory-like ears
- ears that require supports or snap easily

## Paw / Leg Language

Paws and legs must communicate a low, sturdy capybara stance while preserving printability.

Must define later:

- number of visible paw forms
- paw separation language
- leg/body integration
- default stance width
- relief toe marks, if allowed

Forbidden drift:

- long thin limbs
- separated toes
- support-dependent leg gaps
- human-like shoes as base identity
- paws hidden completely by costume in standard variants

## Default Stance

Status: TBD — REQUIRES APPROVED VISUAL MASTER.

Candidate stance families:

- grounded standing loaf
- seated compact figure
- upright mascot stance

The approved default stance must:

- remain stable as a physical object
- show enough capybara identity from front/3/4/side views
- support variants without changing the whole body architecture
- be compatible with support-free FDM goals

## Curvature / Shape Language

CAPICAPI form language should favor:

- continuous rounded masses
- broad readable planes
- simple convex transitions
- intentional flattened/contact zones where needed for print/display
- soft chamfers for FDM survivability

Avoid:

- noisy surface texture
- fragile spikes
- thin curls
- high-frequency fur
- arbitrary blobs with no design logic

## Expression Limits

Allowed expression space:

- calm
- curious
- sleepy
- proud
- surprised
- mildly serious
- mildly happy

Forbidden expression space:

- aggressive
- horror/gore
- realistic distress
- exaggerated rage
- emotion requiring micro facial detail
- expression that changes the core eye/muzzle family

Expressions must be tested on the same base face, not by redesigning the character each time.

## Accessory Zones

Allowed zones:

- head top/front
- face overlay
- torso/front
- side body
- back
- base/feet contact zone where appropriate

Accessory rules:

- accessory is secondary to the base Capi
- accessory must be removable in visual analysis without destroying recognition
- accessory must use fused, thickened, support-aware geometry in 3D
- accessory may not define the head/body silhouette more strongly than the base form

## Immutable Visual Features

To be finalized after visual master approval. Current provisional immutable features:

- capybara-derived broad muzzle
- small integrated ears
- simple calm eye family
- compact sturdy body
- low paw/leg language
- FDM-friendly rounded forms
- role/costume subordinate to base identity

## Flexible Visual Features

Current provisional flexible features:

- role costume
- accessory type
- expression within approved range
- color palette within AMS Lite constraints
- surface relief patterns
- stance variation after master approval

## Explicit Forbidden Drift

Reject candidates that drift into:

- generic cute animal mascot
- teddy bear
- hamster/guinea pig
- dog/cat/rabbit
- realistic capybara figurine
- chibi human in capybara costume
- accessory-first toy where base Capi disappears
- AI-generated style inconsistency between variants
- visual detail that cannot later become FDM geometry

## Required Phase 1A Outcome

Phase 1A does not approve a final character. It must produce four materially different visual direction packages and a human decision about which direction, if any, should proceed to Phase 1B.

Human decision options:

- approve one direction for Phase 1B reference pack development
- request revisions to one or more directions
- reject all directions and restart exploration
- combine specific traits with a written rationale

No final visual freeze occurs in Phase 1A.
