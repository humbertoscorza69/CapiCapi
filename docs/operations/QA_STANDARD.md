# QA STANDARD v1.0

Status: DRAFT
Date: 2026-09-04

## Purpose

QA protects product quality, brand consistency, experiment integrity, and factual claims.

## QA Domains

- phase gate compliance
- Capi visual consistency
- DFM compliance
- print test measurement integrity
- content claim accuracy
- approval evidence
- metadata completeness
- security hygiene

## Status

QA outputs use:

- `PASS`
- `FAIL`
- `BLOCKED`
- `NEEDS_REVIEW`

## Evidence

QA must link to source files, metadata records, Drive file IDs, or measured data. QA must not approve a claim because it "looks plausible."
