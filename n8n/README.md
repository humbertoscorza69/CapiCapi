Status: RESERVED, NOT IMPLEMENTED

This directory reserves version-controlled architecture for future n8n workflows.

## Folders

- `workflows` - exported workflow JSON
- `subworkflows` - reusable workflow modules
- `templates` - starter workflow templates
- `schemas` - n8n-specific validation schemas
- `prompts` - prompts consumed by n8n nodes or agent calls
- `fixtures` - test fixtures for workflow development

## Phase 0 Boundary

No live n8n workflows are created in Phase 0.

Future workflows must use stable IDs and metadata schemas. They must not rely on Drive folder names as the database.
