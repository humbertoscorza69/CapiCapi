Status: DRAFT
Date: 2026-09-04

Agents are specifications first. They are not activated runtimes yet.

- mission
- responsibilities
- allowed tools
- allowed files/documents
- forbidden actions
- inputs
- structured outputs
- memory/source-of-truth documents
- KPIs
- escalation conditions
- handoff rules
- stop conditions
